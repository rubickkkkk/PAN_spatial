# SICS: Super-slide and UKF248_T_1

Install `requirements.txt` in a Python environment and select that environment's
Jupyter kernel. Run `01_super_slide` first, then `02_UKF248`, each from its own directory.

- `01_super_slide/SICS_super_slide.ipynb`: binary spot-state input, artificial
  hexagonal grid, 50 randomizations with seed 186, and a reference matrix.
- `02_UKF248/UKF248_T_1_SICS_step_by_step.ipynb`: the UKF248_T_1 calculation
  using the reference matrix produced by `01_super_slide`, followed by the
  log2 transformation in Python.
- Notebook copies ending in `_executed.ipynb` include execution results.
- `01_super_slide/figures/super_slide_spatial_layout.pdf`: full-grid and local
  adjacency views; PNG and SVG copies are included. Run `plot_super_slide.py`
  with actual Arial fonts installed to regenerate the figure.

Both modules count same-state events once and use lower-triangle totals
including the diagonal. Totals exclude pseudocounts. Spot-state data contain
only binary presence labels, with no continuous state layers.

The sample workflow exports the normalized ratio as `SICS_ratio` and the final
transformed score as `SICS_log2 = np.log2(SICS_ratio)`. The transformation is
applied once, after normalization. Values below zero are retained; a ratio of
1 corresponds to a log2 score of 0. Reference matrices and adjacency counts
remain on their raw scale. No separate R transformation step is required.

`02_UKF248/results/UKF248_T_1_score_matrix.csv` contains ratios;
`02_UKF248/results/UKF248_T_1_log2_score_matrix.csv` contains log2 scores.
The state-pair and MES_Hypo--MES_Core tables contain both score columns.
The result AnnData stores the ratio matrix in `uns['sics_scores']` and the
log2 matrix in `uns['sics_scores_log2']`.

The binary spot-state labels originate from real experimental data.
The super-slide input uses sequential row identifiers from `SPOT_000001` to
`SPOT_033872` and no observation metadata columns. Its grid is generated by
the notebook; the input file itself contains no coordinates or graph.

The super-slide uses `np.random.seed(186)` and `np.random.shuffle` (MT19937):
one initial shuffle, followed by 50 cumulative shuffles. The sample notebook
reads `01_super_slide/results/UKF_reference_raw.csv` directly and checks its
SHA-256 against the accompanying manifest. Keep both module directories together.

The package includes inputs, results, tests, dependency versions, and SHA-256
checksums. No external data paths or Squidpy installation are needed to run
the notebooks.

After generating the shared reference, run the sample checks and regenerate
its executed notebook and outputs with:

```bash
python 02_UKF248/validate_demo.py
```

This validates both score scales and repeats the sample workflow in a separate
directory. The package demonstrates the shared reference and one sample;
it does not assign HiLink/LoLink groups or perform cohort-wide robustness analyses.
