# PANZONER Demos

- `Visium_PANZONER/`: binary Hypo input, region detection, and six outward layers.
- `Xenium_PANZONER/`: ROI AnnData, PAN boundary detection, and distance zones.

Each folder contains the input data, executed notebook, clean notebook template, HTML view, run script, and results. Open `demo.ipynb` or `demo.html` to view the workflow.
